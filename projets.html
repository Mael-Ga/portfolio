SLASHER (mcslasher.com)

Java (Paper API 1.21.10) | Architecture Distribuée Asynchrone
Production / Live

Développement complet du backend d'un jeu multijoueur asymétrique compétitif (1vsN). L'architecture logicielle a été conçue sur mesure pour traiter des volumes massifs de paquets et d'événements physiques sans pénaliser la boucle d'exécution principale. End-to-end backend engineering for an asymmetric competitive multiplayer game (1vsN). The architecture was custom-tailored to process high-throughput packet streams and spatial state calculations without blocking the main event tick loop.

  • Optimisation Concurrence : Déportation des calculs non-bloquants sur un pool de threads asynchrones dédiés, maintenant un tick-rate rigoureusement stable à 20 TPS. Concurrency Optimization : Delegated non-blocking computations onto dedicated asynchronous thread pools, enforcing a solid 20 TPS tick-rate.
  • Protection Mémoire : Audit et neutralisation des fuites de mémoire (garbage collector pressure, cycles de rétention d'entités). Memory Integrity : Comprehensive profiling against GC pauses, memory leaks, and entity retention cycles.
  • Systèmes de Jeu : Implémentation d'arbres de compétences modulaires, mécaniques de furtivité et interface utilisateur réactive. Game Mechanics : Implementation of modular skill progression trees, ray-traced stealth detection, and custom UI elements.
Java Paper API Multithreading Asynchronous I/O 20 TPS Stable Protocols

In-depth investigation of hardware surge resilience and firmware-level hardening against transient voltage spikes and memory corruption exploits.
